# La caisse de la cantine
COACH : Coach MOHAMMED 
Auteur : ABO KOUAME JOSUE       (Delegue groupe 1) 


## Présentation

Ce projet est un programme JavaScript qui calcule le montant d'une commande
à la cantine. Il affiche dans le terminal un récapitulatif avec le nom du
client, une ligne par portion commandée et le total à payer. Il indique
ensuite la monnaie à rendre si le montant versé est suffisant, ou le montant
manquant dans le cas contraire.

## Exécution

Pour lancer le programme, tape dans le terminal :

    node .\cantine.js

## Fichiers du projet

- `cantine.js` : le programme
- `preuves.txt` : les résultats des trois tests
- `README.md` : ce fichier de présentation
